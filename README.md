# RoPhim-Tizen

RoPhim-Tizen is a TizenBrew module that brings Ro Phim to Samsung Tizen TVs.

<!-- [Discord Server Invite](https://discord.gg/m2P7v8Y2qR) -->

# How to install

1. Install TizenBrew from [here](https://github.com/haina2410/rophim-tizen) and follow the instructions.

2. Add the NPM module `@haina2410/rophim-tizen` to the module manager. You can access the module manager by pressing the [GREEN] button on the remote.
